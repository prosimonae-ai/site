Configurer le raccourci
1
Créer la table Supabase
Dans ton tableau de bord Supabase → SQL Editor, colle et execute :
CREATE TABLE steps_log (
date text PRIMARY KEY,
steps integer DEFAULT 0,
updated_at timestamptz DEFAULT now()
);
ALTER TABLE steps_log DISABLE ROW LEVEL SECURITY;
GRANT ALL ON TABLE steps_log TO anon;
2
Créer le Raccourci iPhone
Dans l'app Raccourcis → Nouveau raccourci :

1. Ajoute « Obtenir mes pas » (dans Santé)
2. Ajoute « Récupérer le contenu d'une URL » avec :
URL : https://vxzjfwjxgewdqvfdsxjm.supabase.co/rest/v1/steps_log

Méthode : POST

En-têtes :
apikey → [ta clé anon]
Content-Type → application/json
Prefer → resolution=merge-duplicates

Corps (JSON) :
{
"date": "[Variable : Date actuelle, format YYYY-MM-DD]",
"steps": [Variable : Résultat des pas],
"updated_at": "[Variable : Date actuelle, format ISO8601]"
}
3. Ajoute « Ouvrir les URL » → ce site
3
Ajouter à l'écran d'accueil
Dans le raccourci → ··· → « Ajouter à l'écran d'accueil ». Dès que tu appuies dessus, tes pas s'envoient et le site s'ouvre à jour.
4
Automatisation (optionnel)
Raccourcis → Automatisation → + → Heure → toutes les heures → même raccourci sans ouvrir le site. Données toujours à jour en fond.
